# Rare Book Catalog

### Bib record notes

Local notes, that are not savable only to the IZ, should include a $5 DGW. Use the 590 for specific local notes, but for the 562, 563, and others, include the $5. These are not included in the OCLC record, and should only be in Alma.&#x20;

In all other cases, DCRMB cataloging should follow other note formats for collection, gift, etc notes.&#x20;

### Holding record notes

Holding record notes follow the prescribed MARC Holdings tags. They do not need $5 DGW.&#x20;
