# POL Creation

{% hint style="info" %}
GWLAI staff use the GWLAI brief record/POL creation request [Google form](https://docs.google.com/forms/d/e/1FAIpQLScP60xeVGUxgETZeeWVdzGHTrBFL3xa__tl_16kV6A4EB_j6g/viewform) when they are ready to place orders.
{% endhint %}

A Google Apps Script runs with each form submission to create the bib/item/POL in Alma, and emails the requester with the POL number and MMS ID created.
