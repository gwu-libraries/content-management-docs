# Activating and Deactivating E-Resources

We usually activate electronic resources for our Institution Zone from the Community Zone. The process varies depending on whether the resources is a collection, database, or portfolio. Note that in Alma terminology, both "collection" and "database" are types of electronic collections.

* **Collection** means an electronic collection in Alma with a full-text service and one or more portfolios attached to that service. It will have the collection type "Aggregator package" or "Selective package."&#x20;
* **Database** means an electronic collection in Alma that does not have a service or portfolio attached. It will also have the collection type "Database."
* A **Portfolio** is an electronic record in Alma that is not a collection and represents a specific title, which can be a book, journal, video, etc. Most portfolios are attached to a specific service and collection, but it is possible to have a stand-alone portfolio. If activating a portfolio in a collection we have not already activated, then activate the colleciton first.

#### Activating Collections

1. Find the collection in CZ. Sometimes this can require some research, if there are multiple possible candidates.&#x20;
2. Click activate, taking you to the Activation Wizard
3. Use the settings below. There may be exceptions in certain cases. Not all collections will offer all options. For example, only selective collections have the Activation Type step.
   1. Library: set to Gelman Library
   2. Mark Bib as suppressed: usually do not check this. We do check this option sometimes if there is good reason to suppress the bib record from public view: if the collection's bib record is just a stub, for example, or if users will only use the title-level portfolios and not the record for the collection itself.
   3. Electronic Collection proxy enabled: select it (except for collections that are fully Open Access)
   4. Electronic Collection proxy selected: choose Default (currently OpenAthens). NOTE: be careful to select Default (currently OpenAthens) and not just OpenAthens!
   5. CDI search activation status: select Active
   6. We only subscribe to some titles in this collection: select Yes (even if we actually do own all titles in the collection)
   7. Activate this collection electronic service: select it. This should always be a Full-text service. We do not normally use any of the other types.
   8. Make service available: select it &#x20;
   9. Automatically activate new portfolios: select this in cases where we have subscribed to the entire package, or leave it unselected if we only subscribe to specific titles within the collection
   10. Automatically delete portfolios removed from service: select this if Automatically activate new portfolios was selected
4. Full text service - proxy setup: set Proxy enabled to Yes, and set Proxy selected to Default (currently OpenAthens). Yes, the proxy setup is done at both the collection level and the service level.
5. Activation Type: select one of the three options:
   1. Activate all: choose this if we are activating all portfolios currently in this collection
   2. Activated electronic collection and selected portfolios via Excel upload: rarely used. Remember that if you want to activate via a spreadsheet upload, you can also do it after activating the collection.
   3. Manual activation: choose this if we only activate selected portfolios after the collection is activated, via the activated collection's portfolio list. You can also choose this if you want to activate the portfolios via Excel upload after you finish uploading the collection.
6. Do not forget to click the final Activate button on the Activation Summary screen to complete the process! Also, note that the total number of items activated will be 2 greater than the number of portfolios, because the total also includes the collection itself and the full-text service.
