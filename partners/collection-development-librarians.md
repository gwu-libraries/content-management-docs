# Collection Development Librarians

All items for RDG should be placed on the "INCOMING" shelves in Gelman 609 (Content Management workroom).

## Reviewing Damaged Items on CDL Review Shelves

The only decision that has to be made is whether the item can be withdrawn or if it should be kept. If it can be withdrawn, place it on the "Withdraw" shelf. If it should be kept, place it on the "Keep" shelf and Content Management will determine whether it can be rebound or needs to be replaced.
